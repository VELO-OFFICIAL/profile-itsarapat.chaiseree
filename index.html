§ 01

เกี่ยวกับฉัน

สวัสดีครับ ผมชื่ออิสระพัฒ ตอนนี้เรียนอยู่ชั้นมัธยมต้น และใช้เวลาว่างส่วนใหญ่ไปกับการสร้างเครื่องมือที่ตัวเองอยากใช้จริง

จุดเริ่มต้นของผมไม่ได้หวือหวาเลยครับ — ผมแค่รำคาญที่ถาม AI แล้วได้คำตอบกว้างๆ ที่เอาไปใช้ต่อไม่ได้ ถามโจทย์เลขก็ได้คำตอบที่ "น่าจะประมาณนี้" ขอสไลด์ก็ได้แค่ข้อความให้ไปทำต่อเอง ผมเลยเริ่มสงสัยว่า ถ้าเราเขียนคำสั่งให้มันดีขึ้น มันจะทำงานได้ดีขึ้นแค่ไหน

คำถามนั้นพาผมไปเรียนเรื่อง Prompt Engineering และระบบ Skills ของ Claude จนกลายเป็นโปรเจ็คแรกคือ AI Skills 8 ตัว ที่ผมออกแบบ ทดสอบ และแก้บั๊กเองทั้งหมด พอมันใช้งานได้จริง ผมก็อยากรู้ต่อว่ามันมีค่าพอให้คนอื่นจ่ายเงินไหม เลยลงมือทำเว็บขายของเองอีกที่หนึ่ง

สิ่งที่ผมสนใจจริงๆ ไม่ใช่การ "สั่ง AI ให้ทำงานแทน" แต่เป็น การออกแบบระบบที่ทำให้ผลลัพธ์เชื่อถือได้ — ตั้งสมมติฐาน ทดสอบด้วยโจทย์ที่รู้คำตอบ ดูว่าพังตรงไหน แล้วแก้ ซึ่งผมว่ามันเป็นวิธีคิดเดียวกับที่ใช้ในการทดลองวิทยาศาสตร์ แค่เปลี่ยนจากหลอดทดลองเป็นโค้ดเท่านั้นเอง

§ 02

ทักษะ

ระดับความชำนาญประเมินจากงานที่เคยทำเสร็จจริง ไม่ใช่จำนวนคอร์สที่ดู

การเขียนโปรแกรม

เขียนโปรแกรมเพื่อแก้ปัญหาจริง ตั้งแต่สคริปต์เล็กๆ จนถึงหน้าเว็บที่ deploy แล้ว

  • Pythonใช้งานคล่อง

    ตรวจคำตอบคณิตด้วย sympy, สคริปต์ประมวลผลข้อมูล

  • JavaScriptใช้งานได้ดี

    ทำเว็บให้โต้ตอบได้ — filter, scroll-spy, theme toggle

  • HTML / CSSถนัด

    เขียนเองทั้งหมดโดยไม่พึ่งเทมเพลตสำเร็จรูป

ออกแบบ AI Skills / Prompt Engineering

ทักษะหลักของผม — ทำให้ AI ทำงานเฉพาะทางได้แม่นและสม่ำเสมอ

  • เขียน Skill Description ให้ trigger ถูกตัวถนัด

    ระบุคำที่ผู้ใช้พิมพ์จริง ไม่ใช่คำที่เราคิดว่าเขาจะพิมพ์

  • ออกแบบชุดทดสอบ (Test Set)ใช้งานคล่อง

    สร้างโจทย์ที่รู้คำตอบล่วงหน้าเพื่อวัดว่า skill ตอบถูกจริง

  • บังคับให้ AI ตรวจงานตัวเองใช้งานคล่อง

    ให้รันโค้ดยืนยันคำตอบก่อนตอบผู้ใช้ ลดการมั่ว

ออกแบบเว็บ & UX/UI เบื้องต้น

คิดจากคนที่จะเข้ามาดู ไม่ใช่จากสิ่งที่ตัวเองอยากโชว์

  • Responsive / Mobile-firstถนัด

    ออกแบบจากจอมือถือก่อน แล้วค่อยขยายขึ้นจอใหญ่

  • ระบบสี & Typographyใช้งานได้ดี

    ใช้ตัวแปร CSS วางระบบ ไม่ hard-code สีทีละจุด

  • เขียน Copy ที่ขายของได้กำลังพัฒนา

    เรียนจากการเขียนหน้าขายจริงแล้วดูว่าคนอ่านแล้วเข้าใจไหม

ตรวจคำตอบด้วยโค้ด ไม่ใช่เดาจากความจำ

ทุกโจทย์ที่มีคำตอบเป็นตัวเลข skill จะสั่งให้รันการคำนวณผ่าน Python เพื่อยืนยันคำตอบก่อนส่งกลับ ลดข้อผิดพลาดที่พบบ่อยใน AI ทั่วไป

verify.py
from sympy import symbols, solve
x = symbols('x')
eq = 2*x**2 - 5*x - 3
solve(eq, x)
# ผลลัพธ์: [-1/2, 3]  ✓ ตรงกับคำตอบที่แสดงให้ผู้เรียน

กระบวนการทำงาน

ผมไม่ได้ "สั่งแล้วจบ" — แต่ละ skill ผ่านวงจรนี้หลายรอบกว่าจะปล่อยออกมา

  1. 01
    ออกแบบ

    กำหนดว่า skill นี้ต้องเก่งเรื่องอะไร ผลลัพธ์หน้าตาแบบไหนถึงเรียกว่า "ใช้ได้" แล้วเขียน description ด้วยคำที่ผู้ใช้จริงจะพิมพ์ เพื่อให้ Claude เรียกถูกตัว

  2. 02
    สร้างชุดโจทย์ทดสอบเอง

    เขียนโจทย์ที่ ผมรู้คำตอบอยู่แล้ว คละระดับง่าย–ยาก รวมถึงเคสหลอกที่ AI มักพลาด เช่น โจทย์ที่มีคำตอบสองค่า หรือคำถามที่กำกวม

  3. 03
    ทดสอบและจดผลจริง

    รันโจทย์ทั้งชุดแล้วบันทึกว่าข้อไหนผิด ผิดเพราะอะไร — คำนวณพลาด อ่านโจทย์ผิด หรือหลุดฟอร์แมตที่กำหนดไว้

  4. 04
    แก้บั๊กจากผลทดสอบ

    แก้ที่ต้นเหตุ เช่น เพิ่มขั้นตอนบังคับให้ตรวจคำตอบด้วย Python หรือระบุโครงสร้างผลลัพธ์ให้ชัดขึ้น แล้ววนกลับไปทดสอบใหม่ทั้งชุด

สิ่งที่ได้เรียนรู้

บทเรียนใหญ่ที่สุดคือ "ถ้าวัดผลไม่ได้ ก็ปรับปรุงไม่ได้" ตอนแรกผมแก้ prompt ตามความรู้สึกว่า "น่าจะดีขึ้น" ซึ่งไม่มีทางรู้เลยว่าดีขึ้นจริงไหม พอเปลี่ยนมาใช้ชุดโจทย์เดิมทดสอบทุกรอบ ผมถึงเห็นตัวเลขชัดๆ ว่าการแก้แต่ละครั้งช่วยหรือทำให้แย่ลง

สิ่งที่ได้เรียนรู้

การทำเว็บขายของสอนผมว่า โค้ดที่ดีไม่ได้แปลว่าขายได้ ตอนแรกผมเขียนหน้าเว็บโดยเริ่มจากอวดว่า skill ทำอะไรได้บ้าง แล้วรู้สึกว่ามันไม่น่าเชื่อถือ พอย้ายส่วน "ปัญหา" กับ "หลักฐานผลลัพธ์จริง" ขึ้นมาก่อนราคา หน้าเว็บก็อ่านแล้วเข้าใจง่ายขึ้นเยอะ

§ 04

เส้นทางการเรียนรู้

ผลงานทั้งหมดไม่ได้เกิดในคืนเดียว — นี่คือลำดับที่มันค่อยๆ ต่อกันขึ้นมา

  1. ม.1

    เริ่มจากความสงสัย

    ใช้คอมพิวเตอร์ทุกวันจนเริ่มสงสัยว่าโปรแกรมที่เราใช้อยู่มันทำงานยังไง เลยลองเขียน Python ตามคลิปสอน เริ่มจากโปรแกรมทายเลขและเครื่องคิดเลขง่ายๆ

  2. ม.2

    จากโค้ดเล่นๆ เป็นโค้ดที่ใช้ได้

    เปลี่ยนจากทำตามคลิป มาเขียนสคริปต์แก้ปัญหาของตัวเองจริงๆ และเริ่มหัด HTML/CSS จนทำหน้าเว็บแรกได้สำเร็จ

  3. ม.2 – ม.3

    ค้นพบว่า "คำสั่งที่ดี" เปลี่ยนผลลัพธ์ได้จริง

    เริ่มศึกษา Prompt Engineering และระบบ Skills ของ Claude อย่างจริงจัง เขียน skill ตัวแรกคือ math-genius แล้วพบว่ามันยังคำนวณพลาด จึงเริ่มทำชุดโจทย์ทดสอบเป็นครั้งแรก

  4. ม.3

    ขยายเป็นทีม 8 skills พร้อมกระบวนการทดสอบ

    ต่อยอดจาก skill เดียวเป็น 8 ตัวครอบคลุมทั้งวิชาการ เครื่องมือทำงาน และการวางแผน พร้อมวางวงจร ออกแบบ → ทดสอบ → แก้ ให้ใช้ได้กับทุกตัวเหมือนกัน

  5. ม.3 · ปัจจุบัน

    เปิด Put SSR.SHOP ออนไลน์จริง

    ออกแบบและเขียนเว็บขายเองทั้งหมด ตั้งราคา วางกลุ่มเป้าหมาย แล้ว deploy ขึ้น GitHub Pages ให้คนทั่วไปเข้าถึงได้จริง

  6. ถัดไป

    เรียนต่อสายคอมพิวเตอร์ / เทคโนโลยีดิจิทัล

    อยากเรียนพื้นฐานให้แน่นอย่างเป็นระบบ ในที่ที่มีครูและเพื่อนที่สนใจเรื่องเดียวกัน

§ 05

เป้าหมายอนาคต

ระยะสั้น · 1–2 ปี

ปิดช่องว่างพื้นฐานให้แน่น

  • เรียนโครงสร้างข้อมูลและอัลกอริทึมอย่างเป็นระบบ ไม่ใช่เรียนเฉพาะตอนต้องใช้
  • ใช้ Git และการเขียนเทสต์ให้เป็นนิสัย ไม่ใช่แค่พอใช้เป็น
  • ลงแข่งเขียนโปรแกรมเพื่อวัดตัวเองกับคนอื่นจริงๆ
  • เรียนภาษาอังกฤษเชิงเทคนิคให้อ่านเอกสารต้นฉบับได้คล่อง

ระยะกลาง · ช่วง ม.ปลาย

สร้างของที่มีผู้ใช้จริงมากกว่านี้

  • เรียนต่อสายคอมพิวเตอร์ / เทคโนโลยีดิจิทัล ที่เน้นการลงมือทำโครงงาน
  • ขยายจาก front-end ไปเรียน back-end และฐานข้อมูลให้ทำระบบครบวงจรได้
  • พัฒนา Put SSR.SHOP ต่อให้มีระบบสั่งซื้อและส่งไฟล์อัตโนมัติ
  • ทำโครงงานร่วมกับเพื่อน เพื่อฝึกทำงานเป็นทีมและใช้ version control จริง

ระยะยาว

เป็นวิศวกรที่สร้างเครื่องมือให้คนไทยใช้ได้จริง

เป้าหมายของผมคือการเป็น AI / Software Engineer ที่ทำเครื่องมือด้านการศึกษา — เพราะสิ่งที่ผมทำมาทั้งหมดเริ่มจากปัญหาของนักเรียนคนหนึ่งที่อยากเรียนให้เข้าใจจริงๆ และผมเชื่อว่ายังมีนักเรียนอีกมากที่เจอปัญหาเดียวกันแต่ยังไม่มีเครื่องมือที่ดีพอ

ทำไมถึงอยากเข้าหลักสูตรนี้

สิ่งที่ผมทำเองได้ มาถึงเพดานแล้ว

ที่ผ่านมาผมเรียนรู้จากอินเทอร์เน็ตเป็นหลัก ซึ่งพาผมมาได้ไกลระดับหนึ่ง แต่ผมรู้ตัวว่าความรู้ที่ได้ยังเป็นหลุมเป็นบ่อ — เก่งบางเรื่องมาก แต่ขาดพื้นฐานบางเรื่องไปเลย

สิ่งที่ผมต้องการจากหลักสูตรนี้คือ ครูที่ชี้จุดบอดที่ผมมองไม่เห็นเอง เพื่อนที่สนใจเรื่องเดียวกันจนคุยกันรู้เรื่อง และโจทย์ที่ยากกว่าที่ผมตั้งให้ตัวเองได้ ผมพร้อมเริ่มจากศูนย์ใหม่ในเรื่องที่ยังไม่รู้ และมีผลงานที่พิสูจน์แล้วว่าถ้าเริ่มอะไรผมจะทำจนเสร็จ
