# พอร์ตโฟลิโอส่วนตัว — อิสระพัฒ ชัยเสรี

เว็บพอร์ตโฟลิโอสำหรับใช้ประกอบการสมัครเรียนต่อสายคอมพิวเตอร์ / เทคโนโลยีดิจิทัล
เขียนด้วย HTML + CSS + JavaScript ล้วน ไม่มี framework ไม่มี build step
เปิดไฟล์ `index.html` ก็ใช้งานได้ทันที

---

## โครงสร้างไฟล์

ไฟล์ทั้งหมดอยู่ระดับเดียวกัน ไม่มีโฟลเดอร์ย่อย เพื่อให้ลากขึ้น GitHub ได้ทีเดียวจบ

```
index.html      ← เนื้อหาทั้งหมดของเว็บอยู่ในไฟล์นี้
style.css       ← ดีไซน์ทั้งหมด (สี ฟอนต์ layout responsive)
main.js         ← ธีมมืด/สว่าง, เมนูมือถือ, ตัวกรอง, scroll-spy
og-cover.png    ← ภาพที่ขึ้นตอนแชร์ลิงก์ (1200×630)
og-cover.svg    ← ไฟล์ต้นฉบับแบบ vector ของภาพด้านบน (ฉบับภาษาไทย)
README.md       ← ไฟล์นี้
```

> โฟลเดอร์ `.claude/` ที่อยู่ในเครื่องเป็นแค่ค่าตั้งต้นของ dev server **ไม่ต้องอัปขึ้น GitHub**

---

## เอาเว็บขึ้นออนไลน์ (แนะนำ GitHub Pages — ฟรี)

ใช้บัญชีเดิมที่ deploy `putssr-shop` อยู่แล้วได้เลย

1. เข้า [github.com](https://github.com) กด **New repository** ตั้งชื่อว่า `portfolio` แล้วเลือก **Public**
2. ในหน้า repo ที่เพิ่งสร้าง กด **uploading an existing file**
3. **เลือกไฟล์ทั้ง 6 ไฟล์พร้อมกัน** (`index.html`, `style.css`, `main.js`, `og-cover.png`, `og-cover.svg`, `README.md`) แล้วลากเข้าไปทีเดียว → กด **Commit changes**
4. ไปที่แท็บ **Settings → Pages**
5. ตรง *Source* เลือก **Deploy from a branch** → branch `main` → folder `/ (root)` → **Save**
6. รอประมาณ 1–2 นาที เว็บจะขึ้นที่
   `https://velo-official.github.io/portfolio/`

> รอบต่อไปที่แก้ไฟล์ แค่อัปโหลดทับแล้ว commit ใหม่ เว็บจะอัปเดตเองภายในไม่กี่นาที

**ทางเลือกอื่น:** ลากไฟล์ทั้ง 6 ไฟล์ไปวางที่ [app.netlify.com/drop](https://app.netlify.com/drop) ก็ได้ลิงก์ทันทีโดยไม่ต้องใช้ Git

### หลัง deploy แล้วต้องแก้ 1 จุด

เปิด `index.html` แล้วเปลี่ยนบรรทัดนี้ให้เป็น URL เต็มของเว็บจริง
เพื่อให้ตอนส่งลิงก์ทาง LINE / Messenger ขึ้นภาพพรีวิวถูกต้อง

```html
<meta property="og:image" content="og-cover.png">
```
เป็น
```html
<meta property="og:image" content="https://velo-official.github.io/portfolio/og-cover.png">
```

## แก้เนื้อหาเองตรงไหน

ทุกอย่างอยู่ใน `index.html` และแบ่งเป็นบล็อกที่มีคอมเมนต์คั่นชัดเจน
(`<!-- ══════ 03 · PROJECTS ══════ -->`) ค้นหาด้วย `Ctrl + F` ได้เลย

| อยากแก้ | ค้นหาคำว่า | หมายเหตุ |
|---|---|---|
| ชื่อ / สโลแกนหน้าแรก | `hero__name` | มีอีกจุดใน `<title>` และ `og:title` ด้านบนสุด |
| ข้อความ "เกี่ยวกับฉัน" | `01 · ABOUT` | |
| ระดับทักษะในแถบ | `--v:78%` | เปลี่ยนตัวเลข % ได้ตรงๆ |
| รายละเอียด Skill 8 ตัว | `s8__i` | 1 `<li>` = 1 skill · `data-cat` คือหมวดสำหรับตัวกรอง |
| ราคา | `s8__price` และ `bundle` | ถ้าเปลี่ยนราคาบนเว็บร้าน อย่าลืมแก้ตรงนี้ให้ตรงกัน |
| ไทม์ไลน์ | `04 · JOURNEY` | **แก้ ม.1 / ม.2 / ม.3 ให้ตรงกับปีจริง** ก่อนส่งกรรมการ |
| เป้าหมาย | `05 · FUTURE` | ปรับให้ตรงกับโรงเรียน/หลักสูตรที่สมัครจริงจะได้เปรียบมาก |
| อีเมล / ลิงก์ติดต่อ | `06 · CONTACT` | อีเมลมี 2 ที่: `href="mailto:..."` และ `data-copy="..."` |

เปลี่ยนสีทั้งเว็บ: เปิด `style.css` แก้แค่บล็อก `:root` บรรทัดบนสุด
(`--accent` คือสีส้มหลัก) ทั้งเว็บจะเปลี่ยนตามทันที

## สิ่งที่เว็บนี้ทำได้

- **Responsive เต็มรูปแบบ** — ออกแบบจากมือถือก่อน ทดสอบที่ 375px แล้วไม่มีการล้นแนวนอน
- **โหมดมืด/สว่าง** — กดปุ่มมุมขวาบน ระบบจำค่าไว้ให้ครั้งหน้า
- **แถบความคืบหน้า + เมนูไฮไลต์อัตโนมัติ** ตามส่วนที่กำลังอ่าน
- **ตัวกรอง Skill** ตามหมวด (วิชาการ / เครื่องมือทำงาน / วางแผนชีวิต)
- **ปุ่มคัดลอกอีเมล** ในหน้าติดต่อ
- **สั่งพิมพ์ได้สวย** — ถ้ากรรมการกด Ctrl+P เมนูและปุ่มจะถูกซ่อน เนื้อหาปรับเป็นขาว-ดำ และลิงก์จะแสดง URL เต็มให้อ่านบนกระดาษ
- **SEO / แชร์ลิงก์ครบ** — `<title>`, meta description, Open Graph, Twitter card, JSON-LD (schema.org Person)
- **เข้าถึงได้** — มีลิงก์ข้ามไปเนื้อหาหลัก, `aria-label` ครบ, กดด้วยคีย์บอร์ดได้ทุกปุ่ม, สีตัวอักษรผ่านเกณฑ์ WCAG AA
- **เคารพ `prefers-reduced-motion`** — ถ้าผู้ใช้ตั้งค่าปิดแอนิเมชันไว้ เว็บจะไม่ขยับ

## รันดูในเครื่อง (ตอนแก้ไฟล์)

เปิด `index.html` ด้วยเบราว์เซอร์ตรงๆ ก็ได้ แต่ถ้าอยากให้เหมือนตอนขึ้นจริง

```bash
python -m http.server 5173
```

แล้วเปิด `http://localhost:5173`
