# พอร์ตโฟลิโอส่วนตัว — อิสระพัฒ ชัยเสรี

เว็บพอร์ตโฟลิโอสำหรับใช้ประกอบการสมัครเรียนต่อสายคอมพิวเตอร์ / เทคโนโลยีดิจิทัล
เขียนด้วย HTML + CSS + JavaScript ล้วน ไม่มี framework ไม่มี build step
ต่อกับ Supabase **โปรเจ็คเดียวกับเว็บ Put SSR.SHOP** สำหรับฟอร์มติดต่อและตัวนับผู้เข้าชม

> เว็บนี้เป็น 1 ใน 3 เว็บที่ใช้ฐานข้อมูลร่วมกัน —
> **Put SSR.SHOP** (`source_site = 'put-ssr-shop'`) · **พอร์ตโฟลิโอ** (`'portfolio'`) · **หน้า admin** (อ่านข้อมูลของทั้งสองเว็บ)

---

## โครงสร้างไฟล์

ไฟล์ทั้งหมดอยู่ระดับเดียวกัน ไม่มีโฟลเดอร์ย่อย

```
index.html            ← เนื้อหาทั้งหมดของเว็บ
style.css             ← ดีไซน์ทั้งหมด (สี ฟอนต์ layout responsive)
main.js               ← ธีมมืด/สว่าง, เมนูมือถือ, ตัวกรอง, scroll-spy
supabase-config.js    ← ★ วางค่า Supabase 2 บรรทัดตรงนี้ (ไฟล์เดียวกับเว็บร้าน)
supabase.js           ← ฟอร์มติดต่อ + นับผู้เข้าชม
supabase-schema.sql   ← สำเนาสคริปต์สร้างตาราง (ตัวเดียวกับเว็บร้าน)
vercel.json           ← ตั้งค่าตอน deploy ขึ้น Vercel
og-cover.png          ← ภาพที่ขึ้นตอนแชร์ลิงก์ (1200×630)
og-cover.svg          ← ไฟล์ต้นฉบับแบบ vector ของภาพด้านบน
README.md             ← ไฟล์นี้
```

> โฟลเดอร์ `.claude/` ในเครื่องเป็นแค่ค่าตั้งต้นของ dev server ไม่ต้องอัปขึ้น GitHub

## ขั้นที่ 1 — ตั้งค่า Supabase

### 1.1 สร้างตาราง (ทำครั้งเดียวต่อ 1 โปรเจ็ค Supabase)

ถ้ารันสคริปต์นี้ตอนตั้งค่าเว็บร้านไปแล้ว **ข้ามข้อนี้ได้เลย** เพราะใช้ตารางร่วมกัน

1. Supabase → **SQL Editor** → **New query**
2. วางเนื้อหาจาก `supabase-schema.sql` ทั้งไฟล์ → **Run** (รันซ้ำได้ไม่พัง)

ไฟล์นี้เป็นสำเนาของ `supabase-schema.sql` ในโฟลเดอร์เว็บร้าน — **ต้องเหมือนกันเสมอ**
ถ้าแก้สคีมาฝั่งไหน ให้คัดลอกทับอีกฝั่งด้วย ไม่งั้นจะเขียนข้อมูลไม่ลง

### 1.2 ใส่ค่าเชื่อมต่อ  ✅ ใส่ให้แล้ว

> ไฟล์ `supabase-config.js` มีค่าจริงอยู่แล้ว ไม่ต้องแก้ ข้อความข้างล่างเก็บไว้เผื่อต้องเปลี่ยนคีย์ในอนาคต

1. Supabase → **Settings → API Keys** คัดลอก
   - **Project URL** เช่น `https://abcdefgh.supabase.co`
   - **anon / publishable** (ขึ้นต้นด้วย `sb_publishable_` หรือ `eyJ`)
2. เปิด `supabase-config.js` แทนที่ `ใส่_PROJECT_URL_ตรงนี้` และ `ใส่_ANON_KEY_ตรงนี้`

```js
window.SUPABASE_CONFIG = {
  url: 'https://abcdefgh.supabase.co',
  anonKey: 'sb_publishable_xxxxxxxx',
  sourceSite: 'portfolio'      // ← ห้ามแก้ค่านี้ เว็บร้านใช้ 'put-ssr-shop'
};
```

> ไฟล์นี้ใช้ค่าเดียวกันทั้ง 3 เว็บ คัดลอกไปวางได้เลย **แก้แค่บรรทัด `sourceSite`**

### ⚠️ ใช้ anon / publishable key เท่านั้น ห้ามใช้ service_role

`anon` key ออกแบบมาให้เปิดเผยในเบราว์เซอร์ได้ ไม่ใช่ความลับ
สิ่งที่ปกป้องข้อมูลจริงๆ คือ Row Level Security ที่สคริปต์ตั้งไว้ให้แล้ว —
ผู้เยี่ยมชม **เขียนได้อย่างเดียว อ่านไม่ได้** ส่วนหน้า admin ต้องล็อกอินก่อนถึงจะอ่านได้

`service_role` key ข้ามระบบความปลอดภัยทั้งหมด **ห้ามใส่ในไฟล์เว็บเด็ดขาด**
ถ้าเผลอ push ขึ้น GitHub ให้เข้า Settings → API → **Reset** ทันที

## ขั้นที่ 2 — Deploy ขึ้น Vercel

**วิธีที่แนะนำ (ผ่าน GitHub — อัปเดตอัตโนมัติทุกครั้งที่แก้โค้ด)**

1. อัปไฟล์ทั้งหมดขึ้น GitHub repo ก่อน (เช่นชื่อ `portfolio`)
2. เข้า [vercel.com](https://vercel.com) → **Sign up** ด้วยบัญชี GitHub
3. กด **Add New → Project** → เลือก repo `portfolio` → **Import**
4. หน้าตั้งค่าไม่ต้องแก้อะไรเลย (Framework Preset = *Other*) → กด **Deploy**
5. รอประมาณ 30 วินาที จะได้ URL ฟรีแบบ `https://portfolio-xxxx.vercel.app`

ต่อจากนี้ทุกครั้งที่ commit ขึ้น GitHub เว็บจะ deploy ใหม่ให้เองอัตโนมัติ

**วิธีลัด (ไม่ต้องใช้ GitHub)** — ลากไฟล์ทั้งหมดไปวางที่ [vercel.com/new](https://vercel.com/new)
หรือ [app.netlify.com/drop](https://app.netlify.com/drop) ก็ได้ลิงก์ทันที

### หลัง deploy แล้วต้องแก้ 1 จุด

เปิด `index.html` เปลี่ยน `og:image` ให้เป็น URL เต็ม เพื่อให้ตอนส่งลิงก์ทาง LINE ขึ้นภาพพรีวิว

```html
<meta property="og:image" content="https://portfolio-xxxx.vercel.app/og-cover.png">
```

## ดูข้อมูลที่เก็บได้

ระหว่างที่ยังไม่มีหน้า admin ให้ดูผ่าน Supabase → **SQL Editor**

```sql
-- ข้อความติดต่อล่าสุดจากเว็บพอร์ต
select created_at, name, contact, product_interest, message
from contact_submissions
where source_site = 'portfolio'
order by created_at desc limit 50;
```

```sql
-- ยอดเข้าชมรายวัน แยกตามเว็บ (view นี้มากับสคริปต์แล้ว)
select * from daily_visits limit 30;
```

### โครงสร้างตารางที่ใช้ร่วมกัน

- `contact_submissions` — `name`, `contact`, `product_interest`, `message`, `source_site`, `created_at`
- `page_visits` — `page_path`, `source_site`, `created_at`

ฝั่งพอร์ตส่ง `product_interest` เป็นหัวข้อที่ผู้ติดต่อเลือก (เช่น *การสมัครเรียน / สัมภาษณ์*)
ส่วนเว็บร้านส่งเป็นชื่อ skill ที่ลูกค้าสนใจ — คนละความหมายแต่ใช้คอลัมน์เดียวกันได้
เพราะแยกด้วย `source_site` อยู่แล้ว

---

## เรื่องความเป็นส่วนตัวของตัวนับผู้เข้าชม

ตาราง `page_visits` เก็บแค่ 3 อย่าง: **หน้าที่เปิด · ชื่อเว็บ · เวลา**

ไม่เก็บ IP · ไม่เก็บ user-agent · ไม่ตั้งคุกกี้ · ไม่มี id ติดตามข้ามเว็บ

นับ 1 ครั้งต่อ 1 แท็บที่เปิด (ใช้ `sessionStorage`) เพื่อไม่ให้กด refresh แล้วยอดเฟ้อ
ถ้า Supabase ล่มหรือยังไม่ได้ตั้งค่า เว็บทำงานปกติทุกอย่าง แค่ไม่บันทึกยอด

## แก้เนื้อหาเองตรงไหน

ทุกอย่างอยู่ใน `index.html` แบ่งเป็นบล็อกที่มีคอมเมนต์คั่น
(`<!-- ══════ 03 · PROJECTS ══════ -->`) ค้นหาด้วย `Ctrl + F` ได้เลย

| อยากแก้ | ค้นหาคำว่า | หมายเหตุ |
|---|---|---|
| ชื่อ / สโลแกนหน้าแรก | `hero__name` | มีอีกจุดใน `<title>` และ `og:title` ด้านบนสุด |
| ข้อความ "เกี่ยวกับฉัน" | `01 · ABOUT` | |
| ระดับทักษะในแถบ | `--v:78%` | เปลี่ยนตัวเลข % ได้ตรงๆ |
| รายละเอียด Skill 8 ตัว | `s8__i` | 1 `<li>` = 1 skill · `data-cat` คือหมวดสำหรับตัวกรอง |
| ราคา | `s8__price` และ `bundle` | ถ้าเปลี่ยนราคาบนเว็บร้าน อย่าลืมแก้ตรงนี้ให้ตรงกัน |
| ไทม์ไลน์ | `04 · JOURNEY` | **แก้ ม.1 / ม.2 / ม.3 ให้ตรงกับปีจริง** ก่อนส่งกรรมการ |
| เป้าหมาย | `05 · FUTURE` | ปรับให้ตรงกับโรงเรียน/หลักสูตรที่สมัครจริงจะได้เปรียบมาก |
| ช่องในฟอร์มติดต่อ | `contactForm` | ถ้าเพิ่มช่อง ต้องเพิ่มคอลัมน์ใน SQL **ทั้ง 2 โฟลเดอร์** |
| อีเมล / ลิงก์ติดต่อ | `06 · CONTACT` | อีเมลมี 3 ที่: `mailto:`, `data-copy=`, และข้อความ error ใน `supabase.js` |

เปลี่ยนสีทั้งเว็บ: เปิด `style.css` แก้แค่บล็อก `:root` บรรทัดบนสุด (`--accent` คือสีส้มหลัก)

## สิ่งที่เว็บนี้ทำได้

- **ฟอร์มติดต่อบันทึกลงฐานข้อมูลจริง** — ตรวจข้อมูลก่อนส่ง มีสถานะกำลังส่ง/สำเร็จ/ล้มเหลว และมีช่องหลอกบอทกันสแปม
- **นับผู้เข้าชมแบบไม่ระบุตัวตน** — ไม่ใช้คุกกี้ ไม่เก็บ IP
- **Responsive เต็มรูปแบบ** — ทดสอบที่ 375px แล้วไม่มีการล้นแนวนอน
- **โหมดมืด/สว่าง** — กดปุ่มมุมขวาบน ระบบจำค่าไว้ให้ครั้งหน้า
- **แถบความคืบหน้า + เมนูไฮไลต์อัตโนมัติ** ตามส่วนที่กำลังอ่าน
- **ตัวกรอง Skill** ตามหมวด (วิชาการ / เครื่องมือทำงาน / วางแผนชีวิต)
- **สั่งพิมพ์ได้สวย** — Ctrl+P จะซ่อนเมนู ปุ่ม และฟอร์ม แล้วแสดง URL เต็มของลิงก์
- **SEO / แชร์ลิงก์ครบ** — meta description, Open Graph, Twitter card, JSON-LD
- **เข้าถึงได้** — ลิงก์ข้ามไปเนื้อหาหลัก, `aria-label` ครบ, ใช้คีย์บอร์ดได้ทุกปุ่ม, สีผ่าน WCAG AA
- **พังแล้วไม่ล่ม** — ถ้า Supabase ใช้ไม่ได้ ฟอร์มจะบอกให้ส่งอีเมลแทน ส่วนอื่นทำงานปกติ
